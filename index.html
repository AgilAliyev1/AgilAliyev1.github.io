About me

I study Information Technologies at ADA University in Baku, and I spend most of my free time on the offensive side of security.

What draws me to penetration testing is the method behind it. You start with almost nothing, an IP range or a login page, and you build a picture piece by piece: which hosts are alive, what they run, how they talk to each other, and where an assumption was made that doesn't hold.

My main interests are network analysis, web application security and the reconnaissance work that comes before any exploit. I like reading packet captures as much as I like popping a shell, and I try to write up what I learn so the next attempt is faster.

Alongside my studies I'm part of a small team building a lightweight vulnerability and cryptographic-configuration scanner, a research project that is still in progress.

Current research

in progress
Project #92 Network Security & Cryptography ADA University team of 3

A lightweight tool for network vulnerability and cryptographic configuration reporting in small organisations.

Small organisations have to find and fix known weaknesses without a dedicated security team. Full scanners are heavy and hard to configure, and lighter tools usually cover only half the job: some match services to CVEs but ignore cryptography, others audit TLS and SSH but don't match CVEs.

We're designing a Python tool that does both. It discovers hosts and service versions, matches them to known CVEs, checks TLS and SSH settings against current guidance, and ranks findings so that the vulnerabilities attackers actually exploit come first, not only the ones with the highest severity score.

Status: problem formulation done · implementation and evaluation in progress · no results yet.
